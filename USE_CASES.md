# DSAgt use cases

Each walkthrough is `use_cases/<name>/README.md`. All eight are published; every one except `plasma_turbulence` has been run end to end (that one has no runnable XGC case available).

| Use case | Summary | DSAgt capabilities exercised |
|---|---|---|
| `microbial_isolates` | Registers fastp and megahit as codes and builds a reproducible short-read QC and assembly pipeline over real sequencing reads. | Registering external binaries as codes, registry search, pipeline planning from best-practice documents, provenance across many samples, datacard base skill, pipeline reconstruction |
| `cryoem` | Curates EMPIAR-10017 micrographs by ingesting cryo-EM quality knowledge, registering curation codes, and running a preprocessing pipeline with the AI-readiness check measuring the curation step. | Knowledge ingest and append, semantic search, KB-guided code generation, code registration and execution with provenance, the AI-readiness check firing unprompted, datacard base skill |
| `vasp_dft` | Converts VASP DFT output into AI-ready records by installing a pymatgen skill, authoring a converter skill, and registering the converter as a code. | Base skill `skill-creator`, skill-source sync, catalog search and install, skill authoring with `save_skill`, code registration, provenance iterated against a reference, pipeline reconstruction |
| `tokamak_stability` | Registers codes for reading, analyzing, and plotting M3D-C1 linear-MHD data, then repackages products as HDF5 and reconstructs a rerunnable script. | Skill-guided code creation from Python modules, registry search, provenance, file-based results for codes with unusable stdout, plot generation, parameterized pipeline reconstruction |
| `combustion_simulation` | Develops a BlastNet-to-WELL converter from format documents, registers converter and checker codes, and iterates against a holdout reference. | Skill authoring with source documents as references, agent-written code, code registration and search, provenance, check-driven iteration with failed runs on record, datacard base skill, parameterized reconstruction |
| `plasma_turbulence` | Registers XGC preprocessing scripts as codes and drives check, preprocess, and validate steps over an ADIOS2 simulation case into GNN-ready npz files. | Native discovery of a pre-placed project skill, registering several scripts from a skill's docs, paired check/operate/check with audit reports, provenance, user confirmation, parameterized reconstruction |
| `aidrin-ai-readiness` | Runs all fifteen AIDRIN metrics on UCI Adult through the `aidrin` base skill and code, each call recorded. | `aidrin` base skill and registered code, batch metric execution, datacard base skill, provenance review from the execution records, MLflow observability |
| `genesis_skills` | Syncs the Genesis catalog, installs the Croissant validator skill, and produces a datacard for a small curated dataset. | In-session `add_skill_source`, catalog search and install, native mirroring of installed skills, datacard base skill, skill execution grounded in domain documents |
